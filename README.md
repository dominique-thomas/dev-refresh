# Dev Refresh

**Dev Refresh** is a mobile-friendly learning and reference tool designed to explore and review modern web development concepts. Organized into short, interactive cards, it provides practical examples, code snippets, and real-world use cases across front-end development and design.

## Features

- Responsive, mobile-first interface with dark mode
- Cards covering HTML, CSS, JavaScript, Browser APIs, UI/UX, accessibility, and working with data
- Interactive examples, code snippets, and practical use cases
- Progress tracking and bookmarked cards using local storage
- Random card discovery and optional knowledge checks

## Purpose

This project serves as a self-paced learning and reference tool for refreshing technical knowledge, exploring browser capabilities, and applying web development concepts through practical examples.

## Technologies Used

- HTML, CSS, JavaScript
- Browser APIs and local storage
